02 — INTEGRACIÓN DE DATOS

ETL: del origen
al conocimiento

ETL es el proceso de extraer datos de distintas fuentes, transformarlos para darles calidad y cargarlos en un destino preparado para el análisis.

Power BITalendApache NiFiAirflow
ERP CRM APIs Archivos
01ExtractExtraer datos desde fuentes heterogéneas.
02TransformLimpiar, normalizar, enriquecer y validar.
03LoadCargar al warehouse, lake o data mart.
Data warehouse Data lake Data mart

Conecta fuentes como ERP, CRM, APIs y archivos planos. Registra la fecha de extracción, conserva el origen de cada dato y define cargas incrementales cuando no sea necesario copiar todo en cada ejecución.

Elimina duplicados, corrige formatos, normaliza unidades y catálogos, enriquece registros con contexto adicional y valida reglas de negocio. Documenta las transformaciones y trata explícitamente los valores faltantes.

Carga los datos procesados en un data warehouse, data lake o data mart. Elige cargas completas o incrementales, comprueba que los registros se escribieron correctamente y prepara el modelo para las consultas analíticas.

UNIVERSIDAD · ACOMPAÑAMIENTO

Prevenir la deserción temprana

PROBLEMA

El equipo detecta retiros, pero demasiado tarde para intervenir.

SOLUCIÓN BI

Integra asistencia, entregas y notas para detectar señales tempranas y priorizar tutorías.

RESULTADO

El equipo recibe alertas priorizadas a tiempo y puede ofrecer acompañamiento antes del cierre del periodo.

La predicción orienta el apoyo, no etiqueta ni reemplaza el criterio del equipo.

COLEGIO · RENDIMIENTO

Mejorar el rendimiento académico

PROBLEMA

Los promedios generales ocultan brechas entre asignaturas y grupos.

SOLUCIÓN BI

Unifica evaluaciones y segmenta resultados por materia, curso y periodo.

RESULTADO

La coordinación identifica asignaturas con brechas y enfoca refuerzos donde más se necesitan.

Compara periodos equivalentes y valida el contexto antes de concluir.
